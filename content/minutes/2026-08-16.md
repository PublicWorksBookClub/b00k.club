#### _Sophist_ reminder for next week: { #sophist-264-c }

> [Andrew] We picked up talking through the 5 forms mentioned the previous week, change, rest, same, different, and that which is. We saw that every form was identical with itself, but different from one another, including that which is. We also learned that the different is a precondition for change. Most importantly, we discovered that when something is not a form, it is not nothing. Therefore that which is not, is not nothing, it is only not-(that which is). We then return to earlier arguments with the sophist with a new understanding of that which is not. The sophist earlier claimed that false speech was impossible because speech concerns being, and so to say that which is not was to speak of non being. Now that we know that which is not is actually being, we have destroyed the sohpists main defense. We are now destroying his last vestiges, and investigating appearance-making and likeness-making.
